管理接口经 SSH 隧道访问。迁移时修改地址，首次连接先核对新服务器的主机指纹。

接入步骤

① 在远端安装部署 Agent，无需 Git / Go。

② 在本机运行「首次接入.cmd」，配置 SSH 密钥。

③ 本机配置游戏仓库路径，安装 Git 和 Go。

④ 本机测试打包，通过后上传维护部署。

完整安装脚本和说明位于软件目录。首次部署前请确认游戏端口与现有服务没有冲突。
